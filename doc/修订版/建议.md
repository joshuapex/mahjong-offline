# 提示词与集成建议（修订版）

本目录修订稿已获确认，并接入 `app/prompts`。通用提示词与对应范围提示词共同用于分析；原稿保留。NAS 需更新1.0.4镜像后才能使用。

## 本次修改依据

- 计分规则来自系统：不固定返还点、Uma 或 Oka，并补齐净点棒与返还点口径的区别。当前所有统计采用管理员默认规则重算，不能按历史录入规则解释这些 pt。
- 保留“分析关系而不是复述数字”的目标，但把“争一能力”等永久能力判断改为当前表现，建议针对可复盘现象。
- 不把0点或负终局记录自动当作飞人，不虚构项目未采集的局内指标。
- 综合有效对局数已经由系统提供，不再让模型猜算。个人输入没有其他玩家的完整同期成绩，不使用原稿三个未实现的数据占位符。
- 取消固定的样本量分段和100分评价。场数是可信度的一部分，不是单独的技术认定门槛。
- 个人优势/不足不强制各两项，报告也不强制六个章节，防止为了模板而重复或编造。
- 网站目前以纯文本显示解读，暂不要求 Markdown 表格、标题标记或加粗。保留普通标题与自然段。
- 补充独立届次提示词，避免将本届走势误称为个人完整历史变化。

## 结构化输入

沿用已有 JSON 结构，不仅把表格转成字符串。通用系统提示词与范围附加指令共同组成 `system` 消息，匿名 JSON 作为 `user` 消息。代码生成的数字与结算拆分是权威输入，提示词解释其含义。

当前已有：场次、顺位次数与比例、pt、平均终局点数、净点棒、实际顺位 pt 得失、结算贡献拆分、波动、最佳/最差单场、最近20次参赛走势、最近/此前窗口、座次统计，以及个人同桌比较。

当前没有：和了率、放铳率、立直率、副露率、局内和了/放铳打点、立直收支、逐巡决策、独立的飞人事件，以及个人页的全体同期玩家基准。

未来扩展需按采集到的真实字段开放分析：局内事件可支持进攻/守备相关指标；牌谱与局面才支持具体决策复盘。不要仅因为提示词写了某个分析维度就让模型假设已有该数据。

## 接入前的检查

1. 数据口径一致：新旧规则、Oka 非零、起始/返还不同、样本长度不同、缺少近期或未同桌样本等场景不出现误算。
2. 数字引用准确：具体差距来自系统真实次数、结算与分解，不从舍入比例倒推。
3. 隐私不扩散：保持玩家 ID 标记，不发送账号、密码、昵称、自由备注或 API 密钥到分析正文。
4. 人工验证文风：用匿名样例试生成，检查是否有结论、证据和解释，是否仍在机械罗列。自动化测试能验证请求和计算，不能替代真实模型的内容审阅。
5. 更新提示词版本：接入后标记旧解读待重新生成，保留旧内容，不自动付费重生成。输出长度与 token 限额要协调，并给生成被截断的情况明确反馈。

以上检查建议用于后续维护；本次接入情况见项目 README。

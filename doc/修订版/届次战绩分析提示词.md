# 届次战绩分析提示词（新增）

请根据随本请求提供的系统 JSON，对选定届次的四人日麻战绩进行分析。计分规则使用系统提供的 `scoring_rule`；这份报告只描述本届，不能借用未提供的其他届或完整历史结论。

1. 开头概括本届格局，给出最关键的发现。
2. 简明评价每位参赛者本届的顺位结构、平均表现与主要得失，参赛场数不同时区分累计贡献和每场表现。
3. 挑选最值得解释的反差，用真实顺位次数、各顺位 pt 得失及点数/Uma/Oka 拆分说明原因；不把结果差距直接归因于攻守技术或打法。
4. 只有本届实际参赛记录支持时才讨论本届内的变化。最近/此前窗口也是本届范围，不能称为长期历史对比。
5. 提出本届最值得复盘的现象，最后简短说明小样本、对手差异和终局数据的局限。

使用普通中文小标题与自然段，不输出重复的排行榜、数据表格、固定实力标签或主观百分制评分。其余遵循通用系统提示词。
